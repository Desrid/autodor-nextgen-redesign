# Матрица визуальных вариантов

Эта таблица фиксирует паттерны с одинаковой задачей, но разной визуальной
реализацией. Пока они остаются отдельными stories: унификация без решения
изменит утверждённый visual system сайта.

| Группа              | Смысл                                    | Визуальные варианты                                                   | Правило выбора                                                                                           |
| ------------------- | ---------------------------------------- | --------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| Контентная карточка | Один переход к подробному материалу      | Сервисная, лояльности, новостная, важная тема, будущий проект         | Выбирать по плотности информации и характеру контента; не объединять в одну форму.                       |
| Статусная карточка  | Показать текущее состояние               | RoadStatusRail, контактная панель                                     | RoadStatusRail — несколько коротких статусов; контактная панель — реквизиты и действия.                  |
| Действие            | Перевести пользователя к следующему шагу | Текстовый CTA, primary button, контурная icon button, floating button | Text CTA — из карточки; primary — в диалоге; icon — локальная навигация; floating — глобальное действие. |
| Выбор раздела       | Сменить контекст без ухода со страницы   | ContactsTabs, HeaderNav megamenu, стрелки rail                        | Tabs — равноправные панели; megamenu — маршрутизация; стрелки — последовательный набор карточек.         |
| Статистика          | Сопоставить проверенные данные           | StatisticsBlock, RoadStatistics                                       | Dashboard — общая картина; RoadStatistics — аналитика одной дороги.                                      |

1. Figma задаёт структуру, но многие карточки содержат placeholders; реальные даты, новости, акции, проекты, контакты и показатели нужно брать из разрешённого действующего сайта.
2. Для «машинки» нет отдельного узла в целевом фрейме; две preview-state должны быть реализованы по строке 16 таблицы и зафиксированы отдельно.
3. В хедере Figma показывает «Закупки», а таблица дополнительно требует «Закупки и реализация» и «Поддержка субъектов МСП» внутри «Ещё». Тексты видимого первого уровня сохраняются по Figma; дополнительные пункты требуют проверки меню/ссылок.
4. Figma не содержит реализационных состояний keyboard, touch, reduced motion, loading/error и no-WebGL. Они задаются требованиями и должны получить отдельные тестовые доказательства.
5. Название canvas содержит завершающий пробел, а название главного frame остаётся техническим. Не переименовывать пользовательские разделы по техническим layer names.
